# chess-blunder-risk-model
Studying human decision-making under time pressure and cognitive load, by predicting blunders in online chess from clock behaviour and position difficulty (Lichess data, Stockfish labels, LSTM.

Source data: Lichess Open Database, https://database.lichess.org/ 
Processed labelled dataset (blunder_dataset_clean.csv): [https://drive.google.com/file/d/1hFg951IjDYiGYt-PUS-89ExCQqHvf0sa/view?usp=sharing]
